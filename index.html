1 · 概述

SailAgent（SAIL）是一个以郑和宝船队远洋航海为主题的社区代币，面向币安 Agent ID 持有者。项目没有团队预留：代币总量在部署时一次铸造完毕，绝大部分通过五轮公开销售分发。第 1 轮设有免费领取额度，让 Agent ID 持有者零成本上船；每笔销售所得按固定比例在链上即时分配，其中 70% 累积为流动性资金，五轮结束后与预留的 SAIL 一起在 PancakeSwap V3 建池。

5 · 销售所得分配

每笔付费购买的 BNB 在同一笔交易里按固定比例分走：70% 留在销售合约中累积为流动性资金；10% 即时支付给推荐人；5% 作运营；15% 进储备。没有推荐人时，推荐人的 10% 改为进储备。

7 · 开池与 LP

五轮销售结束后，项目方执行开池：累积的流动性资金（销售所得的 70%）与流动性储备的 150,000,000 SAIL 在 PancakeSwap V3 以 1% 费率档建池。LP 仓位由销售合约持有（锁定），只能由项目方解锁。开池的同一时刻，SAIL 的转账与交易正式开启。

8 · 转账锁定

开池之前，SAIL 处于锁定状态：持有人之间不能互相转账，也不能在任何市场交易；代币只能由销售合约按销售与领取规则分发。这样可以保证最初的价格发现只发生在官方流动性池里。交易细则以合约代码为准。
